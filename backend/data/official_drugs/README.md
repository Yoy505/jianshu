# 官方药品基础信息导入包

`cde_catalog_2026-09-24.json` 保存 3 条已逐条核对的国家药监局药审中心（CDE）化学药品目录集记录。每条保留批准文号、原始页面、批准日期和核验日期，方便以后复核。

**本基础信息包**只涉及药品注册基础事实，不包含说明书内容；适应症、用法、不良反应、处方／非处方类别、医保及在售状态未作为本包核验字段。导入时临床文案和标签为空，发布状态为 `pending`；任何记录都不能因执行导入命令直接对小程序用户展示。药品批准文号被收录不证明注册证当前有效或药品在售。

另有 `cde_leaflets_internal_2026-09-24.json` 对应 3 份逐份核对的官方 PDF 样本，暂存步骤见 `LEAFLET_STAGING.md`。这些原件仅供本机内部验证，独立存入私有目录并保持 `pending`；说明书 PDF 不通过 Git 分发，也未获得对小程序公开转载的使用依据。

全品类来源清单的接入契约见 `REGULATORY_SOURCE_STAGING.md`：它允许以后接收国产、进口化学药/中药/生物制品及疫苗专项来源记录，保留来源快照和冲突证据，但当前没有全量官方清单可导入。无法从附件可靠取得批准文号或版本日期的说明书进入独立待核队列，流程见 `LEAFLET_INTAKE_STAGING.md`；这类记录不会自动关联 `mp_drugs` 或对外展示。

在 `backend/` 目录运行：

```sh
python scripts/import_official_drugs.py          # 默认 dry-run，只读数据库
python scripts/import_official_drugs.py --apply  # 明确写入，须先完成数据库迁移
```

脚本仅以批准文号识别同一记录。对 `pending` 记录只更新来源可核验的基础事实；对 `published`、`offline` 等非待发布记录跳过，不覆盖编辑内容。增加新记录前应逐条核对官方页面，并记录新的核验日期。
