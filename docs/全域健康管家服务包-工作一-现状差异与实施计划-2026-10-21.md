## 2. 领域模型与状态机（阶段 A 契约，细节见 `docs/api.md` 第四部分）

```
MpPackage 服务包 1 ── n MpPackageVersion 版本（价格/积分价/权益项/有效期/说明/售后，售出后不可改）
     │                      │
     │                      └── current_version_id（上架指向的版本）
     │
     ├── n MpOrder 订单（绑定下单时版本 + 价格快照）── 1..n MpPayment 支付尝试 ── n MpPaymentEvent 回调/对账事件
     │                                            └── n MpRefund 退款记录（人工处理队列）
     │                                            └── 1 MpEntitlement（source=order，每单恰一份）
     └── n MpPurchaseBatch 采购批次（单位 × 版本 × 数量）── n MpBatchRow 名单行 ── 0..1 MpEntitlement（source=batch）

MpOrg 采购单位 ── n MpOrgAccount 单位查看账号（scope=org）
MpPointsAccount 积分余额行（user_id 主键）── n MpPointsEntry 只追加流水（balance_after 留痕）
MpUserConsent 授权记录（purpose/version/text/granted_at/revoked_at）
```

| 对象 | 状态机 | 不变量（数据库层保证） |
|---|---|---|
| MpPackage.status | `draft → on_shelf ↔ off_shelf` | 上架必须指向配置完整的版本（价格 > 0、权益非空、有效期 > 0、售后说明非空），否则 409 返回阻断项 |
| MpOrder.status | `pending_payment →(回调/积分) paid`；`pending_payment →(超时/取消) closed`；`paid → refund_pending → refunded / refund_failed`；`refund_failed → refund_pending` | `UNIQUE(user_id, client_order_id)` 幂等；`total_cents > 0`；`paid` 状态变更用 `UPDATE … WHERE status='pending_payment'` 条件更新 |
| MpPayment.status | `created → success / failed` | `transaction_id` 唯一（微信单号不重复记账） |
| MpRefund.status | `pending → processing → success / failed` | 一单可多条退款记录，但 `success` 总额不超过订单金额（服务层 + 事务） |
| MpPointsEntry | 只追加 | `UNIQUE(biz_type, order_id)`（order_id 非空时）防止同单重复扣减 / 返还；`balance_after >= 0` |
| MpPurchaseBatch.status | `preview → confirmed / cancelled` | 确认前不产生权益；`confirmed` 一次性，重复确认 409 |
| MpBatchRow.status | `valid / duplicate / format_error / over_limit` | `UNIQUE(batch_id, row_no)`；只有 `valid` 行在确认时发权益 |
| MpEntitlement.status | `pending →(claim) active`；`pending →(reject) rejected`；`rejected →(claim) active` | `UNIQUE(order_id)`、`UNIQUE(batch_row_id)`（每来源恰一份）；认领以 `UPDATE … WHERE id=? AND phone=? AND status IN ('pending','rejected')`，重复请求返回同一结果 |

金额全部整数分；时间存 UTC；`valid_until = activated_at(Asia/Shanghai 当日) + validity_days`。

## 6. 验收方案（对应指导第五节）

| 场景 | 自动化证据 | 人工 / 真机证据 |
|---|---|---|
| 服务包浏览 | 未上架 / 已下架 404 或 `purchasable=false`；下单 409 | 模拟器截图 |
