# 药品说明书批量导入实施计划

**日期：**2026-09-24  
**范围（用户于 2026-09-24 明确）：**中国境内全部获批上市的人用药品，包含国产与进口的化学药、中药、生物制品及疫苗；不按当前是否实际销售筛选。以监管批准文号记录建立母表，再分别核对说明书。本文是实施和对账计划，不能作为“说明书已全量入库”或“可公开使用”的证明。

## 当前基线与口径

- 前一批导入了 3 条药品**注册基础资料**，状态为 `pending`。本轮从对应的 CDE 详情页下载并在本地开发库私有暂存 3 份化药 PDF 原件，说明书记录均为 `pending`。另取得 1 份中药和 1 份治疗用生物制品附件，进入独立待核流程的隔离临时库，未写入开发库。说明书医学审核与公开发布数量仍为 0。
- 2026-09-24 核对的 [CDE 化学药品目录集](https://www.cde.org.cn/hymlj/listpage/9cd8db3b7530c6fa0c86485e563f93c7)显示 17,489 条**化药目录记录**。按[《药品注册管理办法》第十八条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_3275cb2a929d4c34ac8c0421b2a9c257.html)，该目录收载新批准上市及通过仿制药质量和疗效一致性评价的化学药品，不是全部获批上市药品的母表，更不是说明书文件数。
- [国家药监局政务服务窗口](https://www.nmpa.gov.cn/zwfwqjd/index.html)分别提供[国产药品](https://app.gjzwfw.gov.cn/jmopen/webapp/html5/datasearchgcyp/index.html)、[进口药品](https://app.gjzwfw.gov.cn/jmopen/webapp/html5/datasearchjkyp/index.html)查询及[疫苗说明书和标签查询](https://app.gjzwfw.gov.cn/jmopen/webapp/html5/apiymsmshbqsjkcx/index.html)。这些是不同查询入口，不能把任一个页面的记录数直接称作全部药品或全部说明书数。查询页面有验证码；不得把人工查询入口当作获准批量数据接口。
- CDE 部分详情页在“说明书”栏提供“下载附件”，例如[盐酸二甲双胍片](https://www.cde.org.cn/hymlj/detailPage/4ea3fb710b568213568f1f069ca039bd)；另有[条目显示“暂无”](https://www.cde.org.cn/hymlj/detailPage/0e9059b6d1ff969a7011fb8bcc68a153)。必须先做全目录覆盖率对账。

### 官方来源分工与当前缺口

| 官方入口 | 可核对的事实 | 不能直接推定的事实 |
|---|---|---|
| 药监局国产、进口药品查询 | 单条注册/批准资料，构建国产与进口覆盖基准的核对入口 | 页面需要检索条件和验证码；未见公开整库导出。不能据此声称已取得全部记录或全部说明书 |
| CDE 化学药品目录集 | 特定范围化药目录记录及部分详情附件 | 不覆盖全部中药、生物制品和历史上市药；目录条数不等于批准文号数或 PDF 数 |
| CDE 上市药品信息 | 按受理号公布的部分药品资料与说明书附件，涉及多个类别 | 受理号条数不等于全部现行上市许可数，也不等于唯一说明书版本数 |
| 药监局疫苗说明书和标签查询 | 疫苗说明书、标签的专项核验入口 | 未见公开整库导出，也不能替代全部生物制品清单 |

截至本文核对时，**未取得覆盖全部品类的官方机器可读批准清单或说明书原件包**，因此既不能给出可信的 2026 年实时全品类总条数，也不能承诺全部说明书入库日期。法规要求[批准上市药品说明书公开并及时更新](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_3275cb2a929d4c34ac8c0421b2a9c257.html)；公开可查与本项目可批量保存、向小程序公开展示是两项需要分别核对的条件。

## 数据链路

1. **取得数据使用依据：**确认来源方提供的文件、接口或允许的获取方式，以及本项目内部存储、全文检索、小程序公开展示、更新与撤回的范围。公开网页可查询不等于已确认批量镜像和商业应用的使用范围。
2. **建立全品类批准基准与覆盖率清单：**以官方来源类别、来源条目 ID、批准文号/注册证号、药品名、剂型、规格、持有人及批准/有效状态为基准；国产与进口、化药/中药/生物制品分别对账，疫苗另与其说明书库核对。只有来源明确显示当前有效时才记为“当前获批”；无法核实的历史批准记录保留为“状态未知”，撤销、注销或过期另列，不能归入现行有效总数。逐条标注说明书链接有无、附件 ID、文件格式、版本日期和异常原因。跨来源同一批准文号、同名不同厂家、一个批准文号多个说明书均单列，不用药名推断唯一性。
3. **原件暂存：**按批导入已取得且可使用的 PDF 或其他原始格式；核验大小、SHA-256、批准标识、药名与原始详情页；原件存私有目录。扫描件或正文不能机器匹配的文件进入人工复核队列，不自动关联到已审核药品。相同原件重跑应幂等，发生变化则新增版本，不覆盖旧版。默认只做 dry-run，明确执行参数后入库为 `pending`。
4. **内容抽取：**PDF 文本、表格和扫描件 OCR 分开处理；保留原文页码和段落位置。抽取失败或信心不足时保留原件并进入人工复核，不能自动补写适应症、用法、禁忌或儿童/孕妇用药信息。
5. **医学与使用范围审核：**核对原件与批准文号、版本时效、变更公告、内容完整性、公开使用依据。审核与发布由不同权限执行；待审新版不得覆盖旧公开版。
6. **公开和更新：**小程序只读取已发布且来源有效的当前版本，明确来源、版本/核对时间及原始链接。撤回或许可失效应立即让列表、详情、收藏入口和缓存停止展示对应说明书。

## 对账指标

每批及最终报告都要分别给出：

| 指标 | 含义 |
|---|---|
| 获批上市注册/批准记录数 | 各官方来源分别统计、去重后的基准；注明数据日期与是否排除撤销/失效记录，不能直接计作说明书数 |
| 有附件条目数 / 无附件条目数 | 官方详情页实际提供附件与显示“暂无”的数量 |
| 获取原件数 / 获取失败数 | 已取得并验证格式的文件及失败原因，按国产/进口与药品类别分别统计 |
| 批准文号匹配数 / 冲突数 | 与药品主数据精确对应及需人工核对的数量 |
| 私有暂存版本数 | 文件校验及幂等去重后的独立版本数 |
| 抽取成功数 / 待人工复核数 | 可供审核的结构化文本与扫描/OCR/解析异常 |
| 待审数 / 已发布数 / 已撤回数 | 工作流状态；不得与“取得原件数”混报 |

## 可交付给数据提供方的资料需求

依据[《药品注册管理办法》关于药品品种档案和说明书公开的规定](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_3275cb2a929d4c34ac8c0421b2a9c257.html)，向数据提供方询问并取得书面答复；本文仅是需求草案，尚未向任何机构发送：

1. 提供截至指定日期的全部境内、境外人用药品批准/注册记录清单，覆盖中药、化学药、生物制品及疫苗，明确有效、注销、撤销、过期及状态未知的判断字段；提供稳定来源记录 ID 和批准文号/注册证号。
2. 提供各记录对应的经核准说明书原件、版本日期、附件 ID、文件哈希、更新及撤回记录；说明缺失说明书如何标识，是否存在一个批准文号多个版本或多个文号共享说明书的情况。
3. 说明交付格式、全量和增量更新频率、校验与失败重试方式，以及本项目可否在私有库保存、全文检索、向小程序用户展示说明书及提供原件链接；明确适用条件、费用和撤回要求。
4. 若无法提供全量资料，请按来源和品类明确可提供范围。项目据此形成可核验的覆盖率，不以第三方库或自动生成文本补足缺失原件。
