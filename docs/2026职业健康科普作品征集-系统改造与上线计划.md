# 2026 职业健康科普作品征集：系统改造与上线计划

版本：2026-09-24。依据用户提供的《2026 职业健康科普作品征集项目.docx》（2 页）制定。文档中的活动描述是需求依据，不是对现有代码或上线状态的证明。

## 1. 项目边界与现状

- 新活动主题为职业健康科普，主办方在项目书中写为「天津健树科技有限公司」，承办载体写为「杏临汇微信公众号」。原文学活动属于另一活动，本地数据库已有已入选作品；历史稿件原样保留，不改名挪用。
- 作者站现以职业健康征集为唯一对外页面；旧文学页面和公开投稿/展示 API 已下线。原流程依赖短信登录且预发布/生产短信通道未接入。作者站和后台通过同域 `/api/` 反向代理连接服务端。
- 本轮提供职业健康征集入口、Word/视频投稿和后台处理链路；旧文学活动仅留存数据库历史与审计记录。小程序、医疗服务、健康档案不纳入本轮。

## 2. 项目书明确的活动规则

| 项目 | 活动文档内容 | 系统处理 |
|---|---|---|
| 方向 | 职业病危害防护、办公人群肌肉骨骼健康、职场心理健康疏导、新就业形态劳动者健康保护、职业健康法律科普、职场急救、工作场所健康生活方式，且用语为「包含但不限于」 | 七项快捷选择，另有「其他」自由填写 |
| 图文 | 1000–3000 字，提交 Word 文档 | 接受可安全解析字数的 `.docx`；旧 `.doc` 请另存为 `.docx` |
| 视频 | 3–10 分钟，至少 1080P，MP4 | 校验真实文件类型、时长和横屏/竖屏分辨率 |
| 作者信息 | 姓名、工作单位、联系电话、作品简介 | 投稿时必填，文件与信息仅供授权后台查看 |
| 评审 | 2026-10-08 至 11-12 初筛；11-13 至 12-05 七区复评；12-10 全国终评和线上分享 | 首页展示为评审安排，不当作投稿截止时间；后台先建立可追踪的基础状态和审核记录 |
| 荣誉 | 区域优秀作品有电子荣誉证书 | 不展示项目书未确定的奖级、名额、奖金 |

项目书**未确定**投稿起止日期、最大文件大小、视频编码、七区归属算法、有效邮箱、通知渠道、版权/肖像/第三方素材授权或撤稿修改流程。技术层面的上传上限可先设为 Word 10 MiB、视频 300 MiB，并在页面明确标为「平台上传限制」，不得误写成主办方活动规则。

## 3. 作者与运营流程

1. 作者从独立网页进入活动介绍，读到主题、两种作品格式、作者资料要求及评审安排；入口应在桌面和手机浏览器均可直接打开。
2. 作者在 `/submit` 选择图文或视频，填写作品标题、方向、姓名、单位、电话和简介，选取对应文件，阅读并确认**仅为本次投稿接收、评审与联系使用**的资料处理说明。此处不沿用旧文学活动的公开展示授权，也不要求尚不可用的短信登录。
   联系电话由作者自行填写，当前无验证回执；后台应把它用于联系核实，不据此认定作者身份已核验。
3. 网关在解析大文件前限制同 IP 的上传频率、并发及请求体大小；API 在接收后验证字段、实际文件内容、体积、Word 字数或视频元数据，文件写入不对公网开放的目录。同一表单与同一文件使用 UUID 幂等标识重试，已落库时比对文件 SHA256 后返回原回执；换文件或换字段须作为新投稿。只有文件和数据库记录都成功持久化，才返回回执编号；失败不显示「投稿成功」。
4. 授权运营人员在后台查看列表和详情、受控下载原文件、登记审核状态与意见。公开网页不展示作者电话、单位或未获单独授权的作品。
5. 通知、公众号收录、区域证书和全国展示属于后续运营动作，只有取得真实执行结果后才能标记已完成。回执编号目前仅作投稿凭据，不作为无验证码的个人资料查询凭证。

## 4. 开发里程碑与验收

| 阶段 | 交付 | 验收证据 |
|---|---|---|
| R1 作者可投稿 | 活动首页、公开投稿表单、作品文件校验、私有存储、数据库记录及回执；旧文学入口下线 | 手机/桌面可进入；有效 Word/MP4 返回持久化回执；不合格文件、缺字段、关闭投稿、超限均明确拒绝；同一编号、同一表单及同一文件重试返回原回执，不同文件返回冲突 |
| R2 后台可处理 | 有权限的列表/详情/文件下载/审核记录；管理后台入口 | 非授权请求不得获得作者资料或文件；每次审核可追踪操作人、时间、结果 |
| R3 联调与发布准备 | 数据库迁移、同域 API 反代、上传大小与超时、备份与监控、真实环境联调 | 构建和自动化测试通过；在预发布环境实测文件提交→后台审核→下载；公网域名与 HTTPS 可访问 |
| R4 运营上线 | 正式开放、投稿渠道对外公布、初筛/复评/终评执行 | 主办方确认下列待决策项，真实环境复测通过；发布记录与回滚方案齐备 |

## 5. 上线前待确定

1. 投稿开始及截止时间、时区，以及截止后能否修改/撤回。项目书给出的是评审时间，不能代替截止日期。
2. 主体名称与隐私告知的最终文案；现有旧站条款使用「健树科技（天津）有限公司」，与项目书「天津健树科技有限公司」不一致。
3. 后续公众号收录、公开展示、视频肖像/声音与第三方素材所需的单独授权文本和记录。当前投稿同意仅覆盖接收、评审和联系。
4. 七区划分依据与作者归属字段；证书制作、通知方式、复评和终评操作负责人。
5. 正式网站域名、存储容量、文件安全扫描与备份、真实服务器配置。当前本机可开发验证，不等于公网已经发布。

旧文学征文网页与公开 API 不再对外提供；历史数据库表、迁移记录及后台审计继续保留。新活动不得引用旧活动「每人最多三篇」「匿名」「热榜点赞」和奖金信息作为默认规则。

## 6. 批次记录（2026-10-08）：两级评审制（方案 B）落地

| 项 | 内容 |
|---|---|
| 状态机 | `submitted →(claim) initial_reviewing →(pass) pending_final →(final pass) accepted`；初审/终审驳回均至 `rejected`；`release` 回 `submitted`。旧 `reviewing` 由迁移改写为 `initial_reviewing`，既有 accepted/rejected 补写 `stage=final` 历史留痕 |
| 权限 | `occupational.review` 移除，拆为 `occupational.initial_review`（admin+editor）与 `occupational.final_review`（仅 admin）；editor 自此可读列表/详情/下载（形式初审需要） |
| 制衡 | 终审校验初审记录 reviewer ≠ 当前操作者（同账号双签 409）；初审软锁 30 分钟（claim/release/pass/reject，超时可接管）；驳回必须填理由；每级结论独立落 `occupational_review_records`（(submission_id, stage) 唯一，终审可选 0–100 分） |
| 作者侧 | 新增公开回执查询 `GET /h5/occupational-submissions/receipt/{receipt_no}`（限流 30 次/时/IP）与 H5 `/receipt` 页面：分阶段进度、驳回理由；不返回任何联系方式。投稿成功卡与顶部导航均加入口 |
| 迁移 | `a8d1f3c6b902`：CheckConstraint 五态 + locked_by/locked_at + 评审记录表（时间列 server_default CURRENT_TIMESTAMP，batch 拆分避免 SQLite 循环依赖）；空库 upgrade→downgrade→upgrade 回环验证通过 |
| 验证 | 后端 110 passed（新增双签/锁冲突/锁超时接管/未领取即操作/editor 越权 403/回执查询/驳回理由 422 等用例）；admin-web、essay-h5 tsc+build 通过；浏览器实测完整链路：admin 领取→释放、editor 领取→初审通过（意见落卡）、editor 无终审表单、admin 终审通过 88 分（双记录卡）、H5 回执查询待终审/终审通过/未通过+理由三种状态 |
| 未验证 | PG 环境的迁移与行锁行为（部署时验证）；生产通知渠道仍缺失（驳回结果作者需自行凭回执查询）；补正重提未实现（驳回后需新 client_submission_id 重新投稿） |
