## 3. 领域模型与状态机（切片 A 契约，细节见 docs/api.md 第五部分）

```
MpEntitlement 权益（工作一）──1:1── StewardServiceInstance 服务实例（UNIQUE(entitlement_id)）
     └─ 懒创建于权益转 active 时；退款作废 / 到期由读路径懒触发迁移

StewardServiceInstance ── n StewardPrepCheck   九项激活门禁（UNIQUE(instance_id, check_type)）
                        ── n StewardTask       履约任务 / 日历（UNIQUE(instance_id, task_key)）
                        ── n StewardPauseRecord 暂停与补时
                        ── n StewardTimelineEvent 状态时间线（只追加）
                        ── n StewardStaff 指派（butler / backup_butler / physician，续期链 renewed_from_instance_id）

状态机：preparing →(九项门禁全过+本人确认) active ↔ paused
        active →(ends_at 到点，懒触发) expired →(复评完成+结案报告) closed
        preparing/active/paused →(权益作废/退款) terminated
幂等：重复激活返回原实例；并发激活条件 UPDATE 只赢一次；任务生成以 task_key 唯一约束兜底
```

| 对象 | 不变量（数据库层保证） |
|---|---|
| 服务实例 | `UNIQUE(entitlement_id)` 一份权益至多一个实例；`ends_at = activated_at + service_days×24h + Σ补偿` 由服务层维护并留时间线 |
| 准备检查 | `UNIQUE(instance_id, check_type)`；自动项状态由服务端实时判定，人工项必须带凭据 |
| 履约任务 | `UNIQUE(instance_id, task_key)`；只追加结果不删除；到期 / 终止不删历史 |
| 暂停记录 | `compensated_seconds` 与任务平移天数留痕；<24h 服务方中断补偿为 0 |
| 时间线 | 只追加；谁（actor）、何时、什么事、依据 |
