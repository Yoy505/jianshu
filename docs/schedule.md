按图中五段时间划分，国庆（10.1–10.7）不排任务；A = 后端/基础设施，B = 前端/小程序。

## 关键路径提醒（决定全局的两件事）

1. **域名备案**：提交到管局审核通常 7–20 个工作日，且国庆 8 天完全顺延 → **9.21 当天必须提交**，预计 10.19–10.25 之间下来。备案完成前：域名不能对外提供 Web 服务（联调走 IP/本地），短信签名无法报备，小程序「服务器域名」无法配置。
2. **数据库（RDS）等云资源**：开通本身半天，但**备案要求先有阿里云服务器**，所以 ECS/RDS/Redis/OSS 也是 9.21 当天买好；RDS 与 ECS 同 VPC 内网互通 + 白名单。
