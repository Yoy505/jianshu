## 1. 阿里云账号（一切的前提）

- 注册 https://www.aliyun.com → **企业账号**（不要个人账号：备案主体、小程序认证、短信签名都要企业资质，个人账号后期改主体很痛苦）。
- 企业实名两种方式（控制台「账号中心-实名认证」）：
  - **法人支付宝授权**（推荐，即时生效）：法定代表人支付宝扫码；
  - **对公打款**（无支付宝时）：阿里云打一笔随机金额到对公账户，回填金额验证（1 个工作日）。
- **安全基线（吸取 ClinInsOS 教训）**：
  - 立刻开通 MFA（账号中心-安全设置）；
  - **不要用主账号 AccessKey**：在「访问控制 RAM」建子账号（如 `deploy`），只授予
    `AliyunECSReadOnlyAccess + OSS 权限`，AK/SK 只放服务器环境变量；
  - ECS 登录用密钥对（ssh key），禁用 root 密码登录。

## 2. 域名（约 ¥30-80/年）

| 项 | 建议 |
|---|---|
| 注册商 | 阿里云（万网），与备案/解析一体化，省事 |
| 后缀 | 首选 **.com**（约 ¥69-79/年）；预算敏感选 .cn（约 ¥29-39/年） |

| 购买路径 | 控制台「域名-注册域名」→ 支付 → **立即做域名实名（企业）**：上传营业执照 + 法人身份证，通常 1 个工作日内过 |
| DNS | 默认用阿里云 DNS（免费），备案下来后在「云解析 DNS」加 A 记录即可 |
| 提醒 | 勾选**自动续费**；域名过期被抢注是常见事故 |

规划两个子域名即可（一条备案覆盖整个主域）：

```
essay.你的域名.com    → ECS（征文 H5 静态站，可选与 api 同机不同 server 块）
```

## 3. 服务器与数据库（核心开支）

**先说结论（推荐配置，兼容排期与预算）：**

| 资源 | 规格 | 计费 | 参考价/年 | 说明 |
|---|---|---|---|---|
| ECS | 2 核 4G，系统盘 40G ESSD Entry，带宽 **按使用流量**（峰值 5-10Mbps） | 包年 | 首年约 ¥300-900（企业新客活动常更低） | 跑 Nginx + FastAPI + Celery + Redis(自装) |
| RDS PostgreSQL | 基础系列 2 核 4G（或入门 1 核 2G），存储 50G | 包年 | 约 ¥1500-3000 | 与 ECS 同 VPC 内网；**可后置**（见下方省钱路径） |
| Redis | 先 ECS 自装（本项目用量小） | — | ¥0 | 量大后再换 Tair/社区版托管 |

**必守的三条硬规则：**

1. **地域必须中国大陆**（北京/杭州等）——境外机房（香港/新加坡）**无法备案**，小程序域名就配不了；
2. **ECS 购买时长 ≥ 3 个月**才生成「备案服务号」（备案系统-备案服务号申请，每台 ECS 一个）；
3. RDS/Redis 与 ECS 选**同一地域同一 VPC**，内网互通零流量费，公网只暴露 ECS 的 80/443。

**省钱路径（预算紧时）**：初期把 PostgreSQL 也自装在 ECS 上（4G 内存单机跑 PG+App 够演示与早期运营），
省下 RDS 的钱；等日活起来或需要自动备份/高可用时再迁 RDS——本项目用 Alembic 迁移链，
`pg_dump` → RDS 恢复 → 改 `DATABASE_URL` 即完成迁移，无锁定成本。**但医疗数据正式运营后建议尽早用 RDS**
（自动备份 + 恢复到秒级，是合规底气）。

ECS 购买路径：控制台「云服务器 ECS-创建实例」→ 地域（如 华北2-北京）→ 架构 x86 → 规格族
通用型 g7/g8i 2C4G → 镜像 **Ubuntu 22.04/24.04** → 存储 ESSD Entry 40G → 带宽「按使用流量」
峰值 10Mbps → 设置密钥对 → 安全组只放行 22/80/443 → 包年支付。

## 4. ICP 备案（关键路径：今天提交）

**入口**：阿里云 APP（推荐，含人脸核验与电子签名）或 beian.aliyun.com。

**材料清单（企业备案，提前拍好清晰照片/扫描件）：**

| 材料 | 注意 |
|---|---|
| 营业执照 | 三证合一新版，四角完整、在有效期 |
| 法人身份证正反面 | 原件拍照，勿截图 |
| 网站负责人身份证正反面 | 可以是法人本人（少传一套材料，推荐法人兼任） |
| 负责人人脸核验 | APP 内完成，背景白墙光线足 |
| 备案服务号 | ECS 满足 ≥3 个月时长后在「备案控制台-备案服务号」领取 |
| 网站信息 | 网站内容选「其他」或「企业官网」，服务类型勾「网站应用」；备注可写「企业健康信息服务与内容管理后台」 |

**流程与时间线（对齐 docs/schedule.md）：**

```
提交 → 阿里云初审（1-2 个工作日，会电话核对，保持手机畅通；材料问题在此打回）
     → 提交管局（天津管局）→ 管局审核 7-20 个工作日（国庆 10.1-10.8 完全顺延）
     → 短信+邮件通知备案号 → 按排期预计 10.19-10.25 下号
```

**常见驳回原因（一次过的要点）**：域名实名信息与备案主体不一致（都用企业主体）；营业执照模糊；
网站服务内容勾选了「医疗」相关却无前置审批（**选企业官网/信息服务，不要勾医疗**，我们的合规边界
本来也是「健康管理信息，不构成诊疗」）；负责人电话打不通。

**备案下来后 30 天内**：登录「全国公安机关互联网站安全管理平台」(beian.mps.gov.cn) 做**公安备案**
（免费，纯线上，别漏，逾期有处罚风险）。

## 5. SSL 证书（免费方案够用）

- 阿里云「数字证书管理服务-SSL 证书-免费证书（20 张/年额度）」→ 申请 DV 证书 → 域名 DNS 验证
  （在阿里云解析自动生效，几分钟签发）→ 下载 Nginx 格式部署。
- 免费证书有效期 90 天：**设日历提醒每 80 天手动换**，或用 certbot/acme.sh 自动续（服务器上跑
  acme.sh + 阿里云 DNS API 最省心）。不放心手动流程再买付费 DV（数百元/年）。
